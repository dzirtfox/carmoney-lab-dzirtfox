## 1. Процесс

Клиент вносит частичное досрочное погашение. График платежей пересчитывается по формуле, заданной типом договора (аннуитет или дифференцированный). Условия договора при этом не меняются.

Кто участвует: клиент, расчётное ядро (изолировано контрактом), бухгалтерия, сервис договоров.

## 2. Правила

| № | Правило |
|---|---|
| П-1 | Тип формулы определяется типом договора: аннуитет / дифференцированный. |
| П-2 | Формула и условия договора не меняются ни при каких обстоятельствах. |
| П-3 | Пересчёт выполняет только utility-функция расчётного ядра; вызывающий код округления не делает. |
| П-4 | Правило округления до копейки: <заполнить — до какого знака и в какую сторону>. |
