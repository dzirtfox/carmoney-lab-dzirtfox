## 1. Процесс

Список заявок с решениями (одобрено / отказано / нужны документы) превращается в пакет персонализированных писем по шаблонам. Письма готовятся к отправке и сопровождаются протоколом «какая фраза откуда взята».

Кто участвует: клиент, сервис рассылки (зона команды), юрист (владелец списка фраз), поддержка.

## 2. Правила

| № | Правило |
|---|---|
| П-1 | Один шаблон на каждое из трёх решений. |
| П-2 | Для отказов формулировка берётся **только** из утверждённого списка фраз. |
| П-3 | Внутренняя причина отказа в письмо не попадает ни в каком виде, включая пересказ. |
| П-4 | Протокол содержит: id заявки, id использованной фразы, id шаблона. |
