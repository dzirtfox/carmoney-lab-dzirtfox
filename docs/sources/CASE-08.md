## 1. Процесс

По VIN из заявки запрашивается справочник (синтетический аналог): пробег, год, комплектация. Данные сверяются с заявкой, считается залоговая стоимость. Если данных по VIN нет — оценка не выдаётся.

Кто участвует: сервис оценки (зона команды), справочник (внешний мок), андеррайтер.

| П-4 | Таймаут обращения к справочнику: <значение>; при таймауте поведение — <заполнить>. |
