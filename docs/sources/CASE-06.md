## 1. Процесс

Список должников (день просрочки, сумма, история контактов) превращается в упорядоченный список на смену коллектора. Задача регулярная: запускается по расписанию, результат — на начало смены.

Кто участвует: коллектор, планировщик (зона команды), комплаенс, клиент.

## 2. Правила

| № | Правило |
|---|---|
| П-1 | Приоритет обзвона: <формула или порядок — заполнить>. |
| П-2 | Запрещённые законом часы и каналы связи: <заполнить, со ссылкой на норму>. |
| П-3 | Ограничения из заметок по клиенту применяются, только если не противоречат комплаенс-правилу. |
| П-4 | Клиент, с которым уже был контакт в эту смену, в список не попадает повторно. |
