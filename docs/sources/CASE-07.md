## 1. Процесс

Подписанный договор сверяется с эталонным шаблоном. Отклонения собираются в список с цитатами из обоих документов и передаются юристу. Вердикт о критичности выносит человек.

Кто участвует: юрист, сервис сверки (зона команды), менеджер продаж.

## 2. Правила

| № | Правило |
|---|---|
| П-1 | Перечень контролируемых пунктов: ставка, предмет залога, порядок расчёта пени, <дополнить>. |
| П-2 | Любое отклонение от шаблона — находка для эскалации. |
| П-3 | Агент не решает, критично отклонение или нет, и не ранжирует находки. |
| П-4 | Каждая находка содержит цитату из договора и цитату из шаблона. |
