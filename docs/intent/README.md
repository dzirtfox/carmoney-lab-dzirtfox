# docs/intent/

Замысел одного изменения: **что и зачем**, без решений о реализации.

Имя файла: `intent_<ID задачи>.md` — в дне 1 это `intent_MILEAGE.md` (1.5.2).

Разделы `intent_MILEAGE.md` (1.5.2):

1. **Замысел** — что меняем.
2. **Зачем** — какую проблему это решает.
3. **Constraints** — ограничения; у каждого числа и правила источник: «ответ в интервью» или «код: <файл>».
4. **Open questions** — у каждого статус: открыт / закрыт и кем.
5. **Не входит** — что сознательно оставляем за рамками.

Intent собирается **после интервью Grill Me** (1.5.1): агент сначала задаёт вопросы,
вы отвечаете, и только потом он пишет файл. Чего не было в ваших ответах и в коде — в
intent быть не должно: вынесите в Open questions. Лог интервью (★ 1.5.1) — `grill_MILEAGE.md`.

Не больше одной страницы. Классов, таблиц БД и эндпоинтов здесь нет — это `plan/`.
Не путайте с `AGENTS.md`: intent про одно изменение, AGENTS.md — про весь проект.
Формат intent эпика в днях 2–3 уточнит ведущий.
