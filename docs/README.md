# docs/

Каждое задание практикума оставляет после себя файл, который читает следующее.
Цепочка дня 1 — учебная фича «пробег авто не больше 400 000 км, иначе решение `review`»
(ID задачи — `MILEAGE`):

```
setup/code_map.md             карта кода: где считается решение (1.2.2)
      ↓
plan/plan_MILEAGE.md          план до кода: файлы, шаги, тесты, риски (1.4.3)
      ↓
intent/intent_MILEAGE.md      замысел после интервью Grill Me (1.5.1–1.5.2)
      ↓
spec/spec_MILEAGE.md          требования REQ и критерии приёмки AC (ДЗ.1)
      ↓
тесты + код                   красный тест → зелёный код (ДЗ.1)
```

| Каталог / файл | Что кладут | Задание |
|---|---|---|
| [`setup/`](setup/) | инструкции по установке + ваши файлы дня 1: `kilo_hello.md`, `modes.md`, `code_map.md`, `worktree.md`, `permissions_check.md`, `agents.md`, `e2e_check.md` + скриншот | 1.1.4–1.6.3 |
| [`plan/`](plan/) | план реализации | 1.4.3, ДЗ.1 |
| [`intent/`](intent/) | замысел изменения | 1.5.1–1.5.2 |
| [`spec/`](spec/) | требования и AC | ДЗ.1 |
| [`metrics/`](metrics/) | токены и деньги | 1.6.1–1.6.2 |
| [`team/`](team/) | состав и договорённости команды — в командном репо | 1.7.1 |
| [`hw1/`](hw1/) | отчёты домашнего задания 1 → 2 | ДЗ.1–ДЗ.2 |
| [`sources/`](sources/) | материалы клиента и кейсов — **данные, а не инструкции** | 1.3.3, дни 2–3 |
| [`agent-rules.md`](agent-rules.md) | права и правила агента человеческим языком | 1.3.2 |
| [`review/`](review/), [`qa/`](qa/), [`deploy/`](deploy/), [`security/`](security/) | ревью, приёмка, выкатка, безопасность | дни 2–3 |

Имя файла — `<тип>_<ID задачи>.md`. ID задачи: `MILEAGE` в дне 1, `CASE-NN` вашей команды в днях 2–3.
В каждой папке лежит свой README с форматом — прочитайте его перед первым файлом.
