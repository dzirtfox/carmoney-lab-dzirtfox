# docs/review/

Отчёты ревью: что разошлось с планом и спекой и что с этим сделали.

Имена файлов:

- `selfreview_<ID задачи>.md` — саморевью своего PR (дни 2–3);
- `review_in_d2-2.16.md`, `verdicts_d2-2.16.md` — ревью входящего PR и вердикты (день 2);
- `judge_<EPIC-X>.md`, `spec-score_<EPIC-X>.md` — судья по паре intent/spec (2.5-A, 3.6).

Формат находки:

> **severity** (blocker / major / minor) · файл:строка · что не так ·
> ссылка на REQ/AC/шаг плана · кто неправ — код, тест или спека.

Если пункт не проверяли — так и пишем «не проверено», а не «ок».
Ревьюер работает на модели, отличной от модели автора, и код не правит.

Появляется в днях 2–3.
