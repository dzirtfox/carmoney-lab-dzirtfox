# docs/deploy/

Как сервис поднимается локально и выкатывается на стенд.

Имя файла уточнит ведущий в днях 2–3. В дне 1 сервис поднимается только локально (`make up`).

Что должно быть внутри:

- локальный URL и URL стенда (порт — из вашего диапазона);
- команды запуска, выката и остановки;
- вывод `curl` по двум проверкам из чек-листа приёмки;
- команда отката на стенде.

Границы на стенде: только пользователь команды `t<NN>`, каталог `/srv/t<NN>/`, проект
`docker compose -p t<NN>` и порты из диапазона команды `3<NN>01–3<NN>10`. Чужие контейнеры, сети и тома
не трогаем, `docker system prune` и `docker volume rm` — только с явного «да» человека.

Появляется в днях 2–3: на стенд выкатываются только командные решения.
