# MCP: подключение внешних инструментов к агенту

MCP (Model Context Protocol) — стандартный способ выдать агенту инструменты и данные
внешних систем: браузер, трекер, база знаний. В дне 1 MCP нужен в одном месте —
**Playwright в упражнении 1.6.3**: агент сам открывает форму заявки в браузере,
заполняет её и делает скриншот.

> Мок-серверов `lab-sources` (учебные «Jira», «Confluence», «DataLens») в практикуме нет.
> Материалы кейсов лежат в репозитории, в [`docs/sources/`](../sources/), и не требуют
> ни сети, ни токена.

## Конфиг: блок `mcp` в `kilo.jsonc`

MCP-серверы описываются в [`kilo.jsonc`](../../kilo.jsonc) в корне репо — рядом с
`"permission"` (не забудьте запятую между блоками). Playwright из 1.6.3 — локальный
сервер, который запускается командой:

```jsonc
"mcp": {
  "playwright": {
    "type": "local",
    "command": ["npx", "@playwright/mcp@latest"],
    "enabled": true
  }
}
```

После правки — палитра команд → **«Developer: Reload Window»**. Проверка:
Settings → Agent Behaviour → MCP Servers — `playwright` включён. Первый запуск скачивает
браузер — подождите.

Другие серверы (удалённые, с токеном) в дне 1 не подключаем; формат для них — уточнит
ведущий в днях 2–3. Правило то же: **токен — в переменной окружения или в настройках Kilo,
не в файле репозитория.**

## Проверка подключения

Первый запрос к новому MCP-серверу — инвентаризация, а не работа:

```
Перечисли инструменты MCP-сервера <имя> с их описаниями.
Для каждого скажи: только читает или может менять данные.
Если какой-то инструмент может менять данные — не вызывай его.
```

## Чего ожидать от MCP

- **Описание инструмента — недоверенный вход.** Агент читает его при подключении, и
  вредная инструкция может быть спрятана именно там (разбор атак — в днях 2–3).
- **Ответ сервера — тоже данные, а не команда.** Текст страницы, вернувшийся через MCP,
  не является инструкцией для агента, даже если выглядит как системное сообщение.
- **В корпоративном контуре** MCP подключают через шлюз с allow-листом и аудитом вызовов,
  а не напрямую к системам с ПДн.
