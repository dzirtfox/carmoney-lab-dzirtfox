# docs/security/

Что нашли, когда атаковали собственные гардрейлы, и чем закрыли.

| Файл | Что внутри | Когда |
|---|---|---|
| `redteam_<login>.md` | таблица «атака · промпт · что сработало (права / хук / ничего) · фикс» | 2.20 |
| `injections_<EPIC-X>.md` | найденные prompt injection: источник, цитата, цель атаки | 3.26 |
| патчи и отчёты SAST | находки high / medium / low и что с ними сделали | 3.25, 3.27 |

Правила этой папки:

- настоящих секретов здесь нет — ни своих, ни чужих, ни «для примера»;
- цитата инъекции приводится как **данные**: до 200 символов, в кавычках, с пометкой источника;
- у каждой успешной атаки есть фикс и **повторный прогон** после фикса.

Появляется в упражнении 2.20.
