# mocks/

Заглушки внешних сервисов, к которым учебный проект ходил бы в реальном контуре.
Настоящие интеграции здесь не используются: ни один запрос наружу из этой папки не уходит.

| Мок | Что изображает |
|---|---|
| `vin-service/` | сервис проверки VIN: марка, модель, год, признак залога |

Данные в моках синтетические. Если добавляете свой мок — держите ту же границу:
никаких реальных VIN, ПДн и адресов внутренних систем CarMoney.
