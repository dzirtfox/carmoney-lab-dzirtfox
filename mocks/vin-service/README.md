# Мок сервиса проверки VIN

Заглушка внешнего сервиса, который в продуктовом контуре отдаёт данные по VIN:
марку, модель, год выпуска и признак залога. В учебном проекте мы к настоящему
сервису не ходим — вместо него этот мок на синтетических данных.

## Контракт

`GET /vin/{vin}` →

```json
{
  "vin": "XTA21099998765432",
  "make": "LADA",
  "model": "Vesta",
  "production_year": 2019,
  "pledge": false,
  "source": "mock"
}
```

Коды ответа: `200` — найден, `404` — не найден, `422` — VIN не проходит формат.

## Запуск

Сейчас мок существует как контракт и набор данных — сервиса за ним ещё нет.
Поднять его и подключить к `backend` через сеть compose — часть работ по эпику.
Наружу порт не публикуем: обращаться к моку нужно из контейнера `backend`.

## Данные

Все VIN в моке сгенерированы: они не принадлежат ни одному реальному автомобилю и
не связаны ни с одним владельцем. Связка «VIN + владелец» — красная зона, в учебный
контур такие данные не попадают.

## Ограничения заглушки

- Залог всегда `false`, кроме VIN из списка `mocks/vin-service/pledged.txt`.
- Задержка ответа не эмулируется — таймауты на этом моке не проверить.
- Истории регистрационных действий нет.
